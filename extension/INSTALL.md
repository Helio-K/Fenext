# Fenext插件安装

本安装包用于桌面 Chrome 和 Microsoft Edge，两款浏览器共用同一个插件文件夹。

1. 解压安装包。
2. 从浏览器右上角菜单进入“扩展程序/扩展 → 管理扩展程序”。
3. 开启「开发者模式」，选择「加载已解压的扩展程序」，选中包含 `manifest.json` 的 `extension` 文件夹。
4. 在 Fenext 的「设置与同步 → 接入与数据」填写备注并生成长期有效的插件接收凭证；页面同时提供服务地址。凭证只显示一次，请当场复制。删除凭证后插件将无法继续连接。
5. 首次点击浏览器工具栏中的 Fenext插件，按引导填写服务地址和接收凭证，点击「连接并继续」。验证成功后会记住连接；以后可通过顶部「连接设置」修改。
6. 在文章页面点击「提取当前页面」，填写「想了解什么？」（选填），核对标题和来源后「保存并整理」。实际提取文字可展开查看或修改。

在 Chrome 和 Edge 中分别安装、分别保存连接。可以使用同一个 Fenext账号，为每个浏览器生成独立接收凭证。

当前未提供 Firefox、Safari 或手机浏览器版本。

## 手动更新

连接后，插件会在每次打开时检查已连接的 Fenext 服务是否发布新版。有更新时点击顶部「下载新版」；底部的「检查更新」也可手动查询。检查失败不会影响收集。

1. 下载并解压新版安装包。
2. 将新 `extension` 文件夹中的内容覆盖到原插件文件夹，保持原文件夹位置。
3. 在 Chrome 或 Edge 的扩展管理页，点击 Fenext插件的「重新加载」。
4. 重新打开插件，底部版本号应已更新，连接设置会保留。

请先保存正在收集的文章，再执行更新。不要移除原插件后重新安装。

0.1.3 及更早版本没有更新提醒，需要先手动升级到带提醒的版本。

## 连接状态同步

0.1.5 起，每次打开插件都会自动确认已保存的连接。Fenext 网页的“来源与插件”会在几秒内显示“已连接”；凭证失效时会提示重新连接。状态属于生成凭证的 Fenext 账号，请确保网页登录的是同一个账号。
