# Fenext V1 发布说明

版本：1.0.0

日期：2026-09-27

交付范围：网页端、macOS ARM64 客户端、Windows x64 客户端、Chrome / Edge 插件
发布性质：个人使用版；未签名桌面包，尚未上线公开服务

## 产品范围

V1 的主场景是电脑端网页阅读：在 Chrome 或 Edge 打开文章，用 Fenext 插件提取当前页，在 Fenext 客户端或网页端的收集箱核对资料和问题，再查看自动整理的知识笔记。客户端负责收集与整理界面，网页内容由浏览器插件提取；公开链接、文字、图片和 PDF 是补充输入方式。网页端与客户端使用同一套服务和账户；客户端额外提供全局快捷键、快捷收集浮窗、托盘及 Obsidian 本地目录同步。

本次以已确认的网页预览版为界面基准，正式版本号为 1.0.0。版本号代表交付基线，不代表 Windows、Edge 实机测试、云部署或所有模型的语义质量已经验收。

## V1 功能

- 统一账户入口：已有账号登录，新账号自动注册；账号数据隔离。
- 资料收集：公开网页、PDF 前 30 页、文字和最多 4 张图片，支持填写想了解的问题和保存草稿。
- 自动处理：新增知识自动保存；重复知识指向已有笔记；补充已有知识生成待审核建议。配置缺失、来源受限和失败保留实际状态。
- 收集箱：相同来源和内容集中展示，不同问题保留为独立任务；内容变化保留版本；资料图标可自选 emoji。
- 知识库：按概念和产品问题浏览、关键词搜索、固定搜索与切换区域。
- 笔记：来源依据、相关知识、讨论、明确修改、更新审核、版本历史及恢复。
- Obsidian 图谱边界：保持 Fenext 知识卡片原有颗粒度；仅导出正文中已有的明确知识链接，不按同源或同题批量生成关系。图谱展示与探索使用 Obsidian，V1 不开发独立图谱界面。
- 来源与插件：公开网页与论文、文字与图片、Chrome / Edge Fenext 插件；安装与连接指引保持简洁。
- 接收凭证：生成时填写备注、显示生成时间、长期有效、可修改备注、可删除；明文仅在创建时显示一次。
- 插件：首次连接引导、当前文章提取与预览、提取后收起重复提示、保存到收集箱、连接状态确认、新版本提醒和手动更新。
- 客户端：连接 Obsidian 知识库后在库内建立 Fenext 专用文件夹，笔记同步后可直接在 Obsidian 查看；另有快捷收集、托盘后台运行、全局快捷键、Markdown/YAML 双向同步、冲突保留及同步状态。
- 桌面图标使用透明圆角底，macOS Dock 与 Windows 快捷方式不再显示原始白底方框。
- 设置：左下角个人菜单提供资料编辑、设置与同步和退出登录。

## 两端的使用关系

网页端是完整的服务发布包，不是只有静态 HTML 的页面。需同时运行 API 和 worker，并保留数据库、图片及加密密钥。`npm run web` 一条命令启动两个进程。

客户端默认连接 `http://127.0.0.1:4310`。它需要网页端服务已启动，不内置云服务；本地服务只在电脑运行时处理任务。部署为独立 HTTPS 服务后，两端可以连接同一个服务，关闭客户端不会中断服务端处理。

## 本次不包含

微信公众号、飞书、知乎专属插件或授权连接器；微信小程序正式发布；微信/手机号登录；扩展商城；客户端自动升级；向量语义搜索；完整项目架构生成；付费及多团队管理。

历史小程序代码、公众号专属接入说明和早期 Figma 原型仅作研究档案，不计入 V1 发布承诺。

## 已知限制

- 桌面安装包未做代码签名、公证；Windows x64 为交叉构建，实际安装与运行需 Windows 验收。macOS Intel 不在本次交付中。
- Chrome / Edge 共用 Chromium MV3 包；Edge 尚无实机验收记录；Firefox、Safari 及手机扩展不支持。
- 插件更新需下载新版、覆盖原文件夹内容并在扩展管理页重新加载；扩展管理页的“更新”不会下载本地解压包。
- AI 整理需要用户配置可用接口和密钥，能力、成本和图片支持取决于提供方；自动化测试不覆盖全部真实语义结果。
- 网页链接只读取实际可访问内容，不绕过验证、登录或付费墙。
- 30 秒轮询同步，不传播文件删除；已有本地附件不自动上传；备份需保留数据库及原加密密钥。
- 当前交付未自动完成公网域名、服务器、HTTPS 或容器上线。
