## 历史档案

早期 Figma 画板脚本和需求讨论稿保留在本机研究目录，不进入公开 V1 仓库。旧微信小程序实验源码集中在 `archive/miniprogram/`，不打包为 V1 客户端，也未通过真机验收。

## 版本规则

应用与网页服务用 `package.json` 版本，V1 基线为 1.0.0；插件使用 `extension/manifest.json`，本次也为 1.0.0，后续可以独立发布修复版。

- 修复或小幅界面调整：1.0.x。
- 保持兼容的新功能：1.x.0。
- 需要迁移或有不兼容行为的大版本：x.0.0，并说明迁移和回退条件。
- 各端只有已完成构建、验证和发布说明的版本才进入发布目录，不用修改包名冒充新构建。

## 版本历史

| 版本 | 状态 | 主要内容 |
|---|---|---|

| 插件 0.1.3–0.1.6 | 历史独立迭代 | 更新提醒、连接状态与品牌调整，已由插件 1.0.0 汇总 |

V1 下载使用 GitHub Release 的 `v1.0.0` 资产，仓库中的 `release/` 为本地打包目录且不提交进 Git；不要将旧小程序包、旧插件和旧客户端混作本次发布。
